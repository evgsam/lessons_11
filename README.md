## Ход выполнения работы

### Этап 1. Загрузка и подготовка данных

1. Скачан предоставленный набор данных `botsv1`, содержащий логи:
   - WinEventLog
   - DNS
2. Данные загружены в `DataFrame` с использованием библиотеки `pandas`.
3. Выполнена нормализация данных:
   - Приведение к единому формату времени.
   - Очистка от пропусков и дубликатов.
   - Преобразование типов данных (где необходимо).

### Этап 2. Анализ данных

#### WinEventLog
Проведен анализ событий по полю `EventID`. Выделены подозрительные события, такие как:
- Неудачные попытки входа (EventID: 4625)
- Успешный вход (EventID: 4624) — в контексте аномалий
- Эскалация привилегий (EventID: 4672, 4673)
- Очистка журнала событий (EventID: 1102)
- Создание/запуск служб (EventID: 7034, 7036)

#### DNS-логи
Проведен анализ DNS-запросов. Подозрительными считались:
- Частые обращения к редким или подозрительным доменам
- Домены с большим количеством поддоменов (DGA-алгоритмы)
- Запросы к несуществующим доменам (NXDOMAIN)
- Запросы к известным вредоносным доменам (по базе)

### Этап 3. Визуализация данных

С помощью библиотек `matplotlib` и `seaborn` построены графики топ-10 подозрительных событий:
- Для WinEventLog — по количеству событий с подозрительными EventID
- Для DNS-логов — по частоте подозрительных доменов
- Объединенный график (по желанию)
